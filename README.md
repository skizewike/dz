## Используемые инструменты и средства диагностики

* **Системная диагностика Windows:** `perfmon.msc` (Системный монитор производительности), `resmon.exe` (Монитор ресурсов), `eventvwr.msc` (Просмотр событий / Windows Event Log)
* **Автоматизация и управление:** Windows PowerShell, Командная строка (`cmd.exe`), утилиты реестра (`regedit`, `reg.exe`)
* **Контроль процессов и зависимостей:** Диспетчер задач Windows, Process Explorer / Process Monitor (Sysinternals)
* **Инфраструктура и развертывание:** Node.js (`http-server`), пакетный менеджер `winget`
